# Mahacrop Agrofoods LLP website

Public site for [Mahacrop Agrofoods LLP](https://mahacrop.com) — frozen foods and agricultural products from Pune.

## Stack

- Next.js 15, React 19, Tailwind CSS
- Hosted as a static marketing site on AWS (S3 / CloudFront / Route 53 for `mahacrop.com`)
- Amplify build config is in `amplify.yml` if you use Amplify instead of a static export

## Local development

```bash
npm install --legacy-peer-deps
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
